Курсовой проект посвящен разработке консольной автоматизированной системы, которая упрощает и ускоряет процесс расчета заработной платы сотрудников высшего учебного заведения (ВУЗа). Программа минимизирует риски ошибок (человеческого фактора) в бухгалтерии, автоматизируя учет окладов, надбавок, налогов и удержаний.

---

## Архитектура и технологии
* **Язык программирования:** C++ (стандарт C++17).
* **Паттерн проектирования:** Архитектурная модель **MVC (Model-View-Controller)** для строгого разделения бизнес-логики, хранения данных и консольного интерфейса.
* **Методологии:** Принципы ООП (инкапсуляция, наследование, полиморфизм), шаблоны (Templates), умные указатели (`std::unique_ptr`).

---

## Логика работы и разграничение прав (Ролевая модель)
Система имеет двухуровневую структуру авторизации (логин/пароль шифруются перед сохранением в базу данных):

1. **Режим Бухгалтера (Администратор системы):**
   * Обладает полным доступом к базе данных сотрудников.
   * Может добавлять, удалять и редактировать записи (ФИО, базовые оклады, назначение надбавок).
   * Управляет общими коэффициентами и формулами расчета.
   * Формирует сводные отчеты и расчетные листки по должностям или по всему ВУЗу.

2. **Режим Сотрудника (Пользователь):**
   * Пользователи проходят регистрацию в системе, привязывая свой профиль к существующей базе данных, созданной бухгалтером.
   * Имеют доступ только для чтения (просмотр личного расчетного листа и детализированного отчета по выплатам).

## 📂 Структура базы данных и файлы
Система использует файловую структуру (текстовые базы данных) для хранения сущностей. 

1. **Нельзя удалять (Глобальные конфигурационные файлы):**
   Эти файлы заданы изначально. Они содержат базовые константы, ставки и формулы. Если их удалить, математическое ядро программы полностью сломается:
   * `rules.txt` — содержит базовые коэффициенты начислений (ставки за стаж, контракт, премии).
   * `rules3.txt` — содержит фиксированные проценты удержаний и налогов (авансовая ставка, пенсионный фонд, подоходный налог).

2. **Можно удалять / Сооздаются автоматически (Файлы динамической БД):**
   Эти файлы программа способна **сгенерировать сама «с нуля»** прямо в процессе работы. Если их удалить, система не выдаст ошибку, а просто начнет вести учет заново по мере добавления данных бухгалтером:
   * `rules2.txt` — бинарная матрица индивидуальных надбавок сотрудников (флаги Y/N; автоматически создается и дополняется при регистрации персонала).
   * **Посадочные файлы должностей** (`rector.txt`, `dean.txt`, `professor.txt` и др.) — создаются автоматически в момент добавления первого сотрудника на соответствующую должность.
   * **Файлы авторизации** (`users.txt`, `credentials.txt`) — создаются автоматически при регистрации первых аккаунтов.
